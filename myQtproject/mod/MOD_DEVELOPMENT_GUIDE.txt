================================================================================
一、模组系统概述
================================================================================

节点模组（NodeMod）是战略地图管理器的扩展机制，允许开发者自定义节点的：
  - 外观渲染（替代默认的文本节点显示）
  - 交互行为（双击、拖放、右键菜单等）
  - 数据序列化（保存/加载自定义数据）
  - 编辑器界面（可选的自定义编辑控件）

模组分为两类：
  1. 主模组（Primary Mod）：绑定到节点的 primary_mod_type，负责节点的核心外观
     - 一个节点最多绑定一个主模组
     - 返回 isPrimary() = true
     - 示例：ImageMod（图片节点）、VideoMod（视频节点）

  2. 辅助模组（Auxiliary Mod）：绑定到 auxiliary_mod_types，叠加渲染/交互
     - 一个节点可绑定多个辅助模组
     - 返回 isPrimary() = false
     - 示例：徽章模组、状态指示模组（待实现）

二、核心文件说明
================================================================================

开发模组时需要参考以下文件：

【必读文件】

1. mod/NodeMod.h
   - 模组基类定义，包含所有需要实现的虚函数
   - 定义了 ModInfo、ModRenderContext、ModMenuContext 等关键结构
   - 路径: mod/NodeMod.h

2. mod/ModManager.h
   - 模组管理器（单例），负责模组注册和节点私有数据管理
   - 关键方法：registerMod()、initNodeModData()、saveNodeModData()
   - 路径: mod/ModManager.h

3. mod/builtin/BuiltinMods.h
   - 内置模组注册入口，新增模组需要在此添加注册代码
   - 路径: mod/builtin/BuiltinMods.h

【示例模组】

4. mod/builtin/ImageMod.h
   - 图片节点模组完整实现，展示：
     * 私有数据结构设计（PrivateData）
     * 路径处理（相对路径 vs 绝对路径）
     * 自定义渲染（onPaint）
     * 双击交互（onMouseDoubleClick）
     * 拖放支持（canAcceptDrop / onDrop）
     * 右键菜单扩展（onContextMenu）
   - 路径: mod/builtin/ImageMod.h

5. mod/builtin/VideoMod.h
   - 视频节点模组完整实现，展示：
     * 视频首帧提取（使用 QMediaPlayer）
     * 占位符绘制（加载失败时的降级显示）
     * 播放按钮图标绘制
   - 路径: mod/builtin/VideoMod.h

【节点渲染集成】

6. ui/NodeGraphicsItem.cpp
   - 节点图形项实现，展示模组如何被调用：
     * paint() 中调用模组的 onPaint()
     * mousePressEvent/mouseMoveEvent 等事件分发
     * 模组私有数据的初始化和清理
   - 路径: ui/NodeGraphicsItem.cpp

【数据模型】

7. core/warroom/war_node.h
   - WarNode 结构定义，包含模组相关字段：
     * primary_mod_type（主模组类型 ID）
     * primary_mod_data（主模组 JSON 数据）
     * auxiliary_mod_types（辅助模组类型列表）
     * auxiliary_mod_data（辅助模组数据映射）
   - 路径: core/warroom/war_node.h

【步骤 1】创建模组类文件

在 mod/builtin/ 目录下创建新的头文件，例如 MyMod.h：

```cpp
// mod/builtin/MyMod.h
#pragma once

#include "mod/NodeMod.h"
#include "core/warroom/war_node.h"

namespace warroom {

    class MyMod : public NodeMod {
    public:
        // ---------- 节点私有数据 ----------
        struct PrivateData {
            // 在这里定义模组需要的运行时数据
            QString someData;
            QPixmap cachedImage;
        };

        // ---------- 基础信息 ----------
        ModInfo getInfo() const override {
            return {
                "builtin.mymod",    // id：必须唯一，建议用 "builtin.xxx" 或 "custom.xxx"
                "My Module",        // name：显示名称
                "0.1.0",            // version
                "your_name",        // author
                "Description...",   // description
                ""                  // icon（可选）
            };
        }
        bool isPrimary() const override { return true; }  // 主模组

        // ... 其他方法实现（见下文）
    };

} // namespace warroom
```

【步骤 3】实现序列化方法

```cpp
// 保存：私有数据 -> JSON
nlohmann::json serialize(void* modData) const override {
    auto* d = static_cast<PrivateData*>(modData);
    if (!d) return {};
    nlohmann::json j;
    j["someData"] = d->someData.toStdString();
    return j;
}

// 加载：JSON -> 私有数据
void deserialize(void* modData, const nlohmann::json& data) override {
    auto* d = static_cast<PrivateData*>(modData);
    if (!d) return;
    if (data.contains("someData") && data["someData"].is_string()) {
        d->someData = QString::fromStdString(data["someData"].get<std::string>());
    }
}
```

【步骤 4】实现渲染方法

```cpp
// 返回 true = 完全替代默认绘制，返回 false = 叠加绘制后继续默认
bool onPaint(const ModRenderContext& ctx, void* modData) override {
    auto* d = static_cast<PrivateData*>(modData);
    QPainter* p = ctx.painter;
    QRectF rect = ctx.rect;

    // 绘制背景
    p->setBrush(QColor(240, 240, 240));
    p->setPen(QPen(QColor(180, 180, 180), 1));
    p->drawRoundedRect(rect, 6, 6);

    // 绘制内容
    if (d && !d->cachedImage.isNull()) {
        p->drawPixmap(rect, d->cachedImage);
    } else {
        p->drawText(rect, Qt::AlignCenter, "Placeholder");
    }

    return true;  // 主模组通常返回 true，替代默认绘制
}

// 推荐节点尺寸
QSizeF getPreferredSize(const WarNode* /*node*/, void* modData) const override {
    auto* d = static_cast<PrivateData*>(modData);
    if (d && !d->cachedImage.isNull()) {
        return QSizeF(d->cachedImage.width(), d->cachedImage.height());
    }
    return QSizeF(160, 60);  // 默认尺寸
}
```

```cpp
bool onContextMenu(const ModMenuContext& ctx, void* modData) override {
    auto* d = static_cast<PrivateData*>(modData);
    if (!ctx.menu) return false;

    // 添加分隔线（区分模组菜单和默认菜单）
    ctx.menu->addSeparator();

    // 添加菜单项
    QAction* action = new QAction("My Action", ctx.menu);
    QObject::connect(action, &QAction::triggered, [this, ctx, d]() {
        // 执行操作...
        if (ctx.requestNodeRefresh) {
            ctx.requestNodeRefresh(ctx.nodeId);  // 请求刷新节点显示
        }
    });
    ctx.menu->addAction(action);

    return true;  // 已添加菜单项
}
```

【步骤 7】注册模组

```cpp
#include "mod/builtin/MyMod.h"

namespace warroom {

    inline void registerBuiltinMods() {
        static bool registered = false;
        if (registered) return;
        registered = true;

        ModManager::instance().registerMod(std::make_unique<ImageMod>());
        ModManager::instance().registerMod(std::make_unique<VideoMod>());
        ModManager::instance().registerMod(std::make_unique<MyMod>());  // 新增
    }

} // namespace warroom
```

================================================================================
四、关键概念详解
================================================================================

【私有数据（PrivateData）】

- 每个节点绑定模组后，模组会为该节点分配一个私有数据实例
- 私有数据由模组自己管理（onCreateNode 分配，onDestroyNode 释放）
- 私有数据不存储在 WarNode 中，只存储在 ModManager 的运行时映射表
- WarNode 只存储可序列化的 JSON 数据（primary_mod_data）

【序列化流程】

保存文件时：
  1. ModManager::saveNodeModData() 被调用
  2. 对每个模组调用 onNodeSaved()
  3. 调用 serialize() 获取 JSON
  4. JSON 写入 WarNode::primary_mod_data
  5. WarNode 序列化到文件

加载文件时：
  1. WarNode 从文件反序列化，primary_mod_data 已填充
  2. ModManager::initNodeModData() 被调用
  3. 调用 onCreateNode() 创建私有数据
  4. 调用 deserialize() 从 JSON 填充私有数据
  5. 调用 onNodeLoaded() 完成初始化

【渲染责任链】

节点绘制时（NodeGraphicsItem::paint）：
  1. 先绘制节点基础背景（可选）
  2. 调用主模组的 onPaint()
     - 若返回 true，停止后续绘制
     - 若返回 false，继续绘制默认内容
  3. 遍历辅助模组，依次调用 onPaint()
  4. 绘制选中框、锚点等 UI 元素

【交互责任链】

鼠标/键盘事件分发：
  1. NodeGraphicsItem 接收事件
  2. 检查只读模式（isReadOnly）
  3. 依次调用模组的 onMousePress/onMouseMove 等
  4. 根据返回值决定是否继续传递：
     - Ignored：继续传递给下一个模组
     - Handled：停止传递
     - Consumed：停止传递并阻止默认行为

【路径处理策略】

参考 ImageMod 的实现：
  - 存储路径优先使用相对路径（相对于文档目录）
  - 若文件不在文档目录下，保留绝对路径
  - 运行时解析：先检查是否绝对路径，否则拼接文档目录

================================================================================
五、模组 ID 规范
================================================================================

- 内置模组：使用 "builtin.xxx" 格式
  - "builtin.image" - 图片节点
  - "builtin.video" - 视频节点
  - "builtin.web" - 网页节点（待实现）

- 自定义模组：使用 "custom.xxx" 或 "作者名.xxx" 格式
  - 避免与内置模组 ID 冲突

六、常见问题
================================================================================

Q: 模组数据什么时候保存？
A: 在保存文件时（WarRoomMainWindow::onSaveAction），会调用 ModManager::saveNodeModData()

Q: 如何在模组中访问模型数据？
A: 通过 getNodeMutable() 获取 WarNode 指针，但注意：
   - 只读模式下不应修改数据
   - 修改后需要调用 requestNodeRefresh 刷新显示

Q: 如何支持拖放？
A: 实现 canAcceptDrop() 返回 true，然后在 onDrop() 中处理数据

Q: 如何添加自定义编辑器？
A: 实现 createEditorWidget() 返回 QWidget，但当前版本暂未完全支持

Q: 辅助模组如何叠加渲染？
A: 辅助模组的 onPaint() 应返回 false，让后续渲染继续
